📚 Maduka University Students Note Portal

A modern web-based platform designed to help students of Maduka University access, share, and manage academic notes efficiently. The portal promotes collaborative learning by providing a centralized repository for course materials, lecture notes, assignments, and study resources.

---

🚀 Features

- 📖 Browse and download lecture notes
- 📤 Upload and share study materials
- 🔍 Search notes by course code or title
- 👨‍🎓 Student-friendly interface
- 📱 Responsive design for mobile and desktop
- 🔐 Secure authentication system
- 📂 Organized note categories by faculty and department

---

🛠️ Technologies Used

Frontend

- HTML5
- CSS3
- JavaScript (ES6)
